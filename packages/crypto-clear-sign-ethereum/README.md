# @hzblj/crypto-clear-sign-ethereum

[![npm](https://img.shields.io/npm/v/@hzblj/crypto-clear-sign-ethereum.svg)](https://www.npmjs.com/package/@hzblj/crypto-clear-sign-ethereum)
[![license](https://img.shields.io/npm/l/@hzblj/crypto-clear-sign-ethereum.svg)](https://github.com/hzblj/crypto-clear-sign/blob/main/LICENSE)

Ethereum clear signing for [`@hzblj/crypto-clear-sign`](https://github.com/hzblj/crypto-clear-sign/tree/main/packages/crypto-clear-sign):
transactions of every type the adapter parses (legacy, EIP-2930, EIP-1559, EIP-7702), EIP-712 typed data and EIP-191 messages, read through the chain client of
[`@hzblj/crypto-ethereum`](https://www.npmjs.com/package/@hzblj/crypto-ethereum) into the shared display model.

Not written yet: this package is a placeholder for its first release. What it will export, and what this README will
cover, is in the [chain package contract](https://github.com/hzblj/crypto-clear-sign/blob/main/docs/chain-package-contract.md).
