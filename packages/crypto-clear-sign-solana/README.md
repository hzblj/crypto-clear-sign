# @hzblj/crypto-clear-sign-solana

[![license](https://img.shields.io/npm/l/@hzblj/crypto-clear-sign-solana.svg)](https://github.com/hzblj/crypto-clear-sign/blob/main/LICENSE)

Solana clear signing for [`@hzblj/crypto-clear-sign`](https://github.com/hzblj/crypto-clear-sign/tree/main/packages/crypto-clear-sign):
legacy and v0 transactions (wire transactions and bare messages), message bytes and off-chain messages, read through the chain client of
[`@hzblj/crypto-solana`](https://www.npmjs.com/package/@hzblj/crypto-solana) into the shared display model.

Not written yet: this package is a placeholder for its first release. What it will export, and what this README will
cover, is in the [chain package contract](https://github.com/hzblj/crypto-clear-sign/blob/main/docs/chain-package-contract.md).
