[![license](https://img.shields.io/npm/l/@hzblj/crypto-clear-sign-bitcoin.svg)](https://github.com/hzblj/crypto-clear-sign/blob/main/LICENSE)

Bitcoin clear signing for [`@hzblj/crypto-clear-sign`](https://github.com/hzblj/crypto-clear-sign/tree/main/packages/crypto-clear-sign):
PSBTs (P2WPKH and Taproot inputs, any output) and messages (BIP-322 and legacy), read through the chain client of
[`@hzblj/crypto-bitcoin`](https://www.npmjs.com/package/@hzblj/crypto-bitcoin) into the shared display model.

Not written yet: this package is a placeholder for its first release. What it will export, and what this README will
cover, is in the [chain package contract](https://github.com/hzblj/crypto-clear-sign/blob/main/docs/chain-package-contract.md).
